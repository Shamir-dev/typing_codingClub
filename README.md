# React + Vite

To set up this project you have to download and run "npm install" command to set up build envrionment
Run "npm run dev" to run this project.


# Introduction 
this is a typing practice like website but aims to improve the code typing skills.
here user can practice on real DSA question that can be used in while developing projects, the format is strictly similar to CodeEditor, so the speed here won't degrade on any coding environment.
